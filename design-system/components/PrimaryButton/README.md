# PrimaryButton

Hlavní tlačítko obrazovky („Fill up & go“, „Back home“, „Choose on the map“) leží přímo na poušti, proto musí být vidět i na světlém písku.

- Jedno na obrazovku, dole přes celou šířku vedle kulatého tlačítka mapy.
- Druhý řádek (`caption`) říká cenu nebo důsledek: „2.0 L from the well“.
- **Dnes** je výplň `terra`, která s pískem splývá (2,2 : 1).
- **Doporučení A**: `night` + 3px `frame` + text `amber`, volitelně ikona vody v `water`.
- Alternativy: B `proposal-water-deep`, C `proposal-terra-deep` (viz sekce Návrhy).

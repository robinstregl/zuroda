# Sheet

Panel, který vyjede zespodu po klepnutí na budovu nebo domov.

- `night`, 3px `frame` bez spodní hrany, rádius `radius-lg` nahoře.
- Titulek `sheet-title` se slabou září, úroveň v `label-caps` / `amber-dim`.
- Info box: lehce zvýrazněná plocha s jemnou linkou, rádius `radius-sm`.
- Chybějící materiál v `ember`. Tlačítko uvnitř panelu je dnes `terra` (na tmavém je v pořádku). Podle výběru u PrimaryButton se sjednotí.

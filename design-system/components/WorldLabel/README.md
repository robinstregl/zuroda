# WorldLabel

Jméno budovy (a cena opravy) plovoucí nad budovou ve vesnici.

- **Dnes**: krémová průsvitná pilulka, hnědý text. Je to starý papírový styl a nesedí k nočnímu UI.
- **Návrh**: malá noční pilulka (`night`, tenký `frame`, text `amber`, `world-label`). Ceny, na které hráč má, v `gold`, ostatní v `amber-dim`.

# ActionButton

Kontextová akce na výpravě u vraku nebo místa na tábor, vedle Zurovy bubliny.

- **Dnes**: žlutá `act` s textem `ink`. Na písku skoro neviditelná (1,1 : 1).
- **Návrh**: noční pilulka, 3px rámeček a text v `gold`, slabá zlatá záře, když jde akce provést. Když nejde, text `amber-dim` a bez záře.
